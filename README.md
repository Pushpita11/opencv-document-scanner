# OpenCV Document Scanner & Image Processing

A Python-based document scanner built using OpenCV and Streamlit.

## Features

- Document image upload
- Grayscale conversion
- Gaussian blur
- Canny edge detection
- Contour detection
- Four-corner document detection
- Perspective transformation
- Scanned document generation

## Technologies

- Python
- OpenCV
- NumPy
- Streamlit
